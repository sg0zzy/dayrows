# DayRows artwork

Place source artwork here (launcher icon, adaptive icon foreground/background, etc.).
The app currently uses a temporary vector launcher icon at
`app/src/main/res/drawable/ic_dayrows.xml`.

Android launcher assets must also be added to the appropriate `res/mipmap-*` or
`res/drawable` directories and referenced by the manifest. Files placed here are
source artwork and are not automatically packaged into the app.
